# 非三维界面复刻：本轮交付

本文记录先前的非三维修改。后续三维改动与最新生产预览见 `../scene-review/README.md`；本目录 `preview-*` 在后续三维调试中也可能更新，不能用来证明三维部分未变化。

视觉基准为 `../image.png`，基准画布为 2444 × 1377。

## 已实现

- 按参考图统一顶部、指标带、工作区、底部图表的比例；统一尺寸变量，替换原有相互覆盖的响应式规则。
- 还原深蓝底色、斜切导航、发光细边、彩色指标图标、数字与单位排版。
- 左侧四项主资源树默认完整显示；右上角光纤图标可展开明细，保留光纤选中功能。
- 三张事件卡按图标、标题、级别、时间、里程、描述分别排版；紧凑窗口将时间移到里程行。
- 两侧面板对齐；状态数值与标签分列；透明度滑块与当前值同行。
- 底部四项指标和三张图表使用统一网格；修复波形抽样漏掉主信号的问题，修正有符号纵轴和时间刻度。
- 底部数据页签支持点击、方向键、Home/End；系统设置关闭后保持原导航选中状态。
- 三维模型、材质、镜头和工程坐标没有修改。场景上方的二维视角按钮按参考重新排版。

## 数据语义

数值、事件、风险等级继续来自现有模拟数据。没有为了匹配参考图而更改光纤总长、设备数量、事件级别或补造全天统计。

因此实时数值、柱状图分布、风险颜色不会与参考图片中的示例数据完全相同。图标为本项目的矢量实现，按参考的造型与配色制作，并非原图图标源文件。

## 验证

已对 2444 × 1377、1920 × 1080、1600 × 900、1280 × 720、1600 × 952 五种画布执行浏览器渲染与布局检查：

- 无整页横向溢出、关键标题裁切、指标数值越界、事件文字重叠。
- 默认资源面板、事件列表、场景状态、底部监测区无额外垂直滚动。
- 设备、历史、分析、实时四个页签，系统设置、光纤明细、透明度操作可用；浏览器无页面脚本错误。
- 已在实际 PySide6 桌面窗口确认新版生产构建可正常显示。
- 类型检查与生产构建、波形抽样回归、原有场景回归、桌面窗口桥接和本地 HTTP 服务测试通过。

`preview-*` 是现有模拟数据的正常界面预览。`dashboard-*` 是布局回归截图，包含紧急等级、长名称和较长时间文字的压力数据；该数据只在隔离的测试浏览器中注入，不影响桌面窗口的数据。`layout-report.json` 保存布局与交互检查结果。

启动项目根目录的 `start.bat` 加载本轮生成的生产构建。
